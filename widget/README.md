# WB Analyzer — Buy Widget

Автономный виджет «Купить PRO» для любой страницы. Создаёт платёж в ЮKassa и выдаёт лицензионный ключ после оплаты.

## Демо
`buy-widget.html` — самодостаточная страница: просто открой в браузере (без сборки).

## Как работает
1. Клик «Купить PRO» → `POST {API_BASE}/licenses` → получает `license_key` + `confirmation_url`
2. Если `confirmation_url` есть (реальная оплата) — открывает вкладку ЮKassa и показывает блок «Я оплатил — получить ключ». **Ключ не показывается до оплаты.**
3. Кнопка проверки → `POST {API_BASE}/licenses/check` → если платёж подтверждён — открывается окно с ключом.
4. Если пришёл `demo: true` (ЮKassa не настроена) — ключ выдаётся сразу с пометкой «демо».
5. Автовозврат: после оплаты ЮKassa редиректит на страницу — виджет сам проверяет платёж и показывает ключ.

## Встраивание на свою страницу
Виджет построен на `data-*` атрибутах и не зависит от стилей страницы (все классы изолированы префиксом `wb-`). Перенеси:
- HTML-блок `<div class="wb-buy" data-wb-widget>…` и модалку `<div class="wb-modal" data-wb-modal>…`
- CSS-блок из `<style>` (префикс `wb-`)
- `<script>` в конце

И укажи свой backend:
```js
var CFG = { API_BASE: 'https://wb-analazuer.ru/api/wb', PRICE: 590 };
```

## Зависимости от backend
| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | /api/wb/licenses | `{ amount: 590 }` | `{ success, demo?, data: { license_key, confirmation_url } }` |
| POST | /api/wb/licenses/check | `{ license_key }` | `{ success, data: { is_valid } }` |

Backend-часть лежит в папке `backend/` (Laravel + ЮKassa).

## Примечание
Демо и лендинг используют одинаковую логику; лендинг держит свою версию в `landing/product.html` (там же оплата, но встроена в страницу).
