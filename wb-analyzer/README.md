# WB Analyzer — Анализ цен и выгрузка CSV

Chrome Extension для продавцов Wildberries. Открываешь поиск/каталог на WB → жмёшь «Анализировать» → получаешь таблицу с градацией выгодности входа и CSV.

## Установка (dev)
1. chrome://extensions → Developer mode ON → Load unpacked → выбери папку `wb-analyzer`
2. Открой https://www.wildberries.ru/catalog/0/search.aspx?search=чехол
3. Клик по иконке → Анализировать страницу → Скачать CSV

## Что делает MVP
- Парсит товары через WB Search API (`search.wb.ru`) + fallback DOM
- Поля: название, бренд, цена, цена без скидки, отзывы, рейтинг, продавец, ссылка
- Анализ: min, медиана, средн, max цены + средний рейтинг
- Градация:
  - 🟢 Выгодно — мало отзывов (<100) и цена >= медианы
  - 🟡 Средне — 100-500 отзывов
  - 🔴 Сложно — >500 отзывов / демпинг + высокая конкуренция
- CSV выгрузка (UTF-8 BOM, Excel-совместимо)
- PRO: бесплатно 20 строк, PRO без лимита (демо-активация любым кодом)

## Монетизация
- Freemium: лимит 20
- PRO: Gumroad / ExtensionPay — `$9` разово или `$5/мес`
- Для MVP: демо-PRO активируется любым кодом в попапе (заменишь на проверку Gumroad License API)
