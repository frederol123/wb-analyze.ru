# WB Analyzer — Анализ цен и выгрузка CSV

Chrome Extension для продавцов Wildberries. Открываешь поиск/каталог на WB → жмёшь «Анализировать» → получаешь таблицу с градацией выгодности входа и CSV.

## Установка (dev)
1. chrome://extensions → Developer mode ON → Load unpacked → выбери папку `wb-analyzer`
2. Открой https://www.wildberries.ru/catalog/0/search.aspx?search=чехол
3. Клик по иконке → Анализировать страницу → Скачать CSV

## Что делает
- Парсит товары через WB Search API (`search.wb.ru`) + fallback DOM
- **Быстрый анализ** — первая страница выдачи
- **Глубокий анализ (PRO)** — пагинация до **300 товаров**
- Поля: название, бренд, цена, цена без скидки, скидка %, отзывы, рейтинг, продавец, рейтинг продавца, ссылка

## Метрики сводки
- Цены: min, медиана, среднее, max
- Спрос: суммарное и среднее число отзывов по нише
- Насыщенность: доля товаров с >500 отзывами
- Концентрация: доля топ-10 товаров в общих отзывах
- Скидки: средний % по нише, доля демпинга (<70% медианы)
- Градация:
  - 🟢 Выгодно — мало отзывов (<100) и цена >= медианы
  - 🟡 Средне — 100-500 отзывов
  - 🔴 Сложно — >500 отзывов / демпинг + высокая конкуренция

## CSV
Выгрузка (UTF-8 BOM, Excel-совместимо) всех полей + скидка/рейтинг продавца.

## PRO / монетизация
- Free: показ до 20 строк, быстрый анализ
- PRO: полная таблица, глубокий анализ до 300 товаров, лицензия 590 ₽ бессрочно
- Бэкенд: Laravel + ЮKassa (СБП/карты), чек НПД автоматически
  - `POST /api/wb/licenses` — создать платёж → `confirmation_url`
  - `POST /api/wb/licenses/check` — проверить ключ
  - `POST /api/wb/licenses/webhook` — вебхук ЮKassa, активация ключа
- Пока ЮKassa в проверке — расширение падает в демо-режим (любой ключ активирует PRO)
