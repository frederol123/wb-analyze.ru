# MVP за 7 дней — Пассивный доход без привлечения клиентов

## Цель
Сделать за неделю продукт, который можно выложить на площадку с собственным трафиком и получать деньги без холодных продаж.

## Выбранное решение: Chrome Extension + Gumroad PRO

### Почему именно это
- **CodeCanyon / WordPress.org** — твой PHP-профиль идеален, но модерация 3-14 дней -> денег на 7-й день не будет
- **Shopify App Store** — модерация 7-14 дней + Billing API -> не влезает в неделю
- **Chrome Web Store** — модерация 1-3 дня, огромный органический трафик из поиска стора, приходит сам
- **Gumroad** — публикация мгновенна, используем как кассу для PRO-версии расширения (ExtensionPay / Gumroad License API)

Go на этой неделе не берем — с 10 годами PHP быстрее сделать на JS + PHP (если нужен бэкенд).

### 3 ниши на выбор (проверенный спрос, низкая конкуренция)
1. **WB/Ozon Helper** — парсер карточки конкурента / трекер цены / выгрузка отзывов в CSV
2. **SEO-микротул** — проверка битых ссылок / мета-тегов / генерация sitemap в 1 клик
3. **AI-помощник** — менеджер промптов / сохранение чатов ChatGPT/Claude в Notion/CSV

MVP = 3 функции: Бесплатно база, PRO ($9-19 разово / $5 мес) — экспорт, лимиты, авто-обновление.

### Стек
- **Frontend:** WXT / Plasmo + Vanilla JS (Manifest V3)
- **Хранение:** Chrome Storage API
- **Платежи:** ExtensionPay или Gumroad License API (1 файл, paywall)
- **Бэкенд (если нужен парсинг):** PHP/Laravel на VPS — твой опыт

### План по дням
**День 1 — Валидация (без кода, 4 часа)**
- Выбрать 1 нишу
- Найти 5 конкурентов в Chrome Web Store, проверить установки >10k и жалобы в отзывах
- Зафиксировать 3 фичи MVP

**День 2-3 — Ядро**
- Manifest V3, popup + content script
- Базовый функционал без бэкенда если возможно

**День 4 — Монетизация**
- Подключить ExtensionPay / Gumroad License API
- Реализовать paywall: if (!licensed) блокировать PRO-кнопки

**День 5 — Упаковка**
- Иконки, 4 скриншота, описание с ключами (влияет на органику стора)
- Privacy Policy (шаблон)

**День 6 — Публикация**
- Залить в Chrome Web Store
- Создать страницу PRO на Gumroad
- Подготовить черновик на Product Hunt

**День 7 — Запуск**
- Сабмит проходит, стор начинает индексацию
- Публикация анонса на r/chrome_extensions, VC.ru, Telegram-каналах продавцов WB (для индексации, не продажи)

### Монетизация и ожидания
- Ожидаемо: $0-50 в первую неделю, $100-300 на 2-4 неделе с органики стора
- Цена: $9-19 разово или $5/мес — низкий порог для импульсной покупки

### Риски
- Модерация стора может затянуться -> иметь запас 2 дня
- Gumroad берет комиссию 10% + Stripe
- Нужен минимальный маркетинг для первичной индексации

### Альтернатива (если не хочешь расширение)
Laravel SaaS Starter Kit на Gumroad ($69) — соберешь за 5 дней из nikotest/laravel, публикация мгновенна, но трафик через Product Hunt/X.
